# CSC 586: Linux System Administration and Security - Summer 2024 - 100% online asynchronous

This course is a hands-on study of operating system 
administration essentials with a focus on systems security 
and time in the lab. Additionally, various script languages 
are taught to provide a basis for understanding and extending 
the system capabilities.
