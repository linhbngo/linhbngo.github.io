# CSC 530: Data Structures 

Data structures are essential building blocks in obtaining efficient 
algorithms. This course aims to introduce students to advanced data structure 
concepts, including geometry (multi-dimensional data structures), dynamic 
optimality, memory hierarchy, hash, integers, dynamic graphs, strings, and 
succinct.
