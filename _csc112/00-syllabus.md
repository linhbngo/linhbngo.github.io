## Course Information

This is an approved Science General Education distributive course.

Introduction to the fundamentals of business computing. Topics include surveys of the
following sub-areas of computer science: hardware/operating systems, programming
languages/software, ethics/social issues, problem solving, and advanced MS Excel and
programming for business use. The course includes laboratory projects in MS Excel and
Python programming.

This offering treats Excel as the primary analytical environment and Python as an
automation layer. No prior programming experience is assumed. We will spend most of
the semester learning to ask questions of data in Microsoft 365 (especially Excel),
then use Copilot as a checked assistant, and finally use Python to repeat work that
should not be done by hand.

This syllabus is subject to change. Please refer to D2L for the latest version.

## Learning Objectives

### Course Student Learning Outcomes (CSLO)

By the end of this course, students will be able to:

1. Understand and implement non-trivial assignments which require comprehension of a
   problem description, software design, and other technical specifics. Assignments
   will be a mix of in-class and outside-class work. *(SLO1)*
2. Develop clear and logically correct algorithms to solve problems stated in written
   form. *(SLO2)*
3. Implement solutions in MS Excel. *(SLO3)*
4. Use appropriate data types, mathematical formulas, and logical expressions in
   their assignments. *(SLO4)*
5. Determine the correctness of worksheets, formulas, and programs. *(SLO5)*

## Course Topics and Tentative Schedule

### Course Topics

- How computers think and store information
    - Instructions, memory, files, and why Excel cells have types
- Data literacy before Excel
    - Observations, variables, messy data, and asking a question first
- Analytical thinking using Excel
    - Formulas and references; functions and logic; charts; Tables; PivotTables; what-if and lookups
- Copilot as a productivity tool, not a shortcut
    - Draft, explain, and *verify* formulas alongside statistical functions
- Python as an automation layer
    - Repeat an Excel analysis in code and check the result
